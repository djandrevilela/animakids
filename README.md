# 🤸 AnimaKids

### Plano de treino, objetivos e presenças da turma, sempre à mão.

## O que é

A **AnimaKids** é a app de treino da turma — pensada para o telemóvel,
para consultar antes de cada treino ou usar em ginásio.

Com ela dá para:

- 📅 **Ver o plano de treino** completo da época, treino a treino
- 🚩 **Consultar os objetivos** de cada valência e o que falta para os atingir
- 📊 **Acompanhar o progresso** de cada atleta, objetivo a objetivo
- 👥 **Organizar os grupos** de trabalho (1, 2 e 3)
- ✅ **Marcar presenças** e treinos já dados
- 📈 **Ver sempre em que fase da época** a turma está

---

## 📲 Instalar no telemóvel

Abre o link da app e:

- **Android (Chrome):** menu ⋮ → *Adicionar ao ecrã principal*
- **iPhone (Safari):** ícone de partilha ⬆️ → *Adicionar ao ecrã principal*

Fica com ícone próprio, abre em ecrã inteiro e funciona mesmo sem internet
para consultar o que já está guardado.

---

## 🔒 Acesso

A app pede uma password de acesso. Fala com a equipa técnica se não a
tiveres.

Os dados sincronizam automaticamente entre os dispositivos configurados
pela equipa técnica — não precisas de fazer mais nada.

---

## 🙈 Sobre privacidade

Para proteger a identidade das atletas, os nomes reais **não aparecem no
código público desta app** — só nos dispositivos autorizados pela equipa
técnica. Se vires nomes como "Atleta A01", é normal: significa que estás
a ver a versão sem os nomes preenchidos.
